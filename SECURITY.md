# Security policy

Bookkeeper Tweaks runs in your browser and has no server of its own. It sends nothing to its developer. The
[privacy policy](PRIVACY.md) describes what it handles.

## Reporting a vulnerability

If you find a security issue, report it privately through the "Report a vulnerability" form on this repository's
Security tab. Please do not report it in a public issue.

Expect a reply within five working days. This project does not run a bug bounty.

## Supported versions

Security fixes go into the latest version published on the Chrome Web Store.
